# ポットリミット計算ルール仕様（実装とテストの「正」）

本ドキュメントの数式と検証ベクタ表は **テストコードの正本**。実装がこの表と食い違う場合、実装が誤り。
表の値を書き換えたい場合は必ず人間（オーナー = 現役ディーラー）に確認する。

---

## 1. 用語と記号

| 記号 | 名称 | 定義 |
|---|---|---|
| `potBefore` | 前ポット | 当該ストリート開始時に確定していた額（前ストリートまでの合計 ＋ アンティ ＋ デッドチップ） |
| `contributions[seat]` | 投入額 | 当該ストリートで各席が出した累計額（ブラインド・ストラドルを含む） |
| `C` | 現在のベット額 | `max(contributions)` = コールすべき水準 |
| `h` | 自分の投入額 | `contributions[hero]` |
| `P` | 現在のポット総額 | `potBefore + Σcontributions`（**`C` も `h` も含む、今テーブル上の全額**） |
| `toCall` | コール額 | `C - h` |
| `trail` | トレイル | `P - C - h`（最後のベットと自分の投入を除いた残り） |

> 注意：`P` は「コール前の、今見えている全チップ」。ここを「コール後」や「自分の分を除く」と誤ると全部ずれる。

## 2. 公式

```
toCall      = C - h
maxRaiseTo  = h + P + 2 * toCall        // ← 実装する唯一の式
maxAddChips = maxRaiseTo - h            // 実際に今出すチップ量 = P + 2 * toCall
minRaiseTo  = C + lastRaiseIncrement    // 直前のレイズ幅ぶん上乗せ（プリフロップ初回は C + BB）
```

**恒等式（暗算用ショートカット。テストで一致を固定すること）**

```
maxRaiseTo = 3 * C + trail        （trail = P - C - h）
```

導出：`h + P + 2(C - h) = P + 2C - h = 3C + (P - C - h)`

### 覚え方（ディーラー向け 3 ステップ）

1. **今テーブルにある全額を数える**（前ポット ＋ 全員の今ラウンド投入額）→ `P`
2. **コール額を 2 倍して足す** → `P + 2 × toCall` ＝ **その人が今出す最大チップ量**
3. **すでに出している自分の分を足す** → **アナウンスする "raise to" の数字**

（自分が未投入なら 2 と 3 は同じ数字になる。プリフロップの BB / SB / ストラドルだけが 3 を必要とする。）

### 端のケース

- **最初のベット**（`C = 0, h = 0`）→ `maxRaiseTo = P`（ポットベット）。
- **スタック上限**：`maxRaiseTo = min(h + P + 2*toCall, h + heroStack)`。上限に達したら all-in 表示。
- **アンティ / BB アンティ / デッドボタンのデッドチップ**：すべて `potBefore` に入れる（＝ポットの一部）。
- **ストラドル**：単なる「大きいブラインド」として `contributions` に入れるだけ。最大レイズ計算は変わらない。
- **金額は必ず整数**（最小チップ単位）。0.5 レートは内部で 2 倍などにスケールする。

### 本アプリで扱わない／ハウスルール依存（v1 で出題しない）

- ストラドルがある場合の **最小レイズ額**（ルーム差が大きい。既定は「ストラドルの 2 倍」、設定で変更可）。
- ショートスタックの不完全 all-in がアクションを再オープンするか（テキサス系共通ルール。モード E で扱う）。
- レーキ計算（将来モジュール）。

## 6. 検証ベクタ：サイドポット

アルゴリズム：投入額の異なる水準を昇順に走査し、各層で `(層の差) × (その層以上を投入した人数)` を積む。
参加資格はその層以上を投入し **かつフォールドしていない** プレイヤー。参加資格が同一の連続層はマージする。

## 8. 不変条件（プロパティテスト）

問題生成器が作る全局面について、以下を 10,000 ケースで検証する。

1. `maxRaiseTo >= minRaiseTo`
2. `maxRaiseTo === 3 * C + (P - C - h)`（ショートカット恒等式）
3. すべての金額が整数かつ 0 以上、最小チップ単位の倍数
4. 局面中の各レイズが `minRaiseTo <= raiseTo <= maxRaiseTo` を満たす（合法な局面のみ生成される）
5. サイドポット総額 ＝ 全プレイヤーの投入額合計（返却分を除く）
