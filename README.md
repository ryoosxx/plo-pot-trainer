# PLO Pot Trainer

ポーカーディーラー向け、PLO ポット計算の練習アプリ。

スマホからは [GitHub Pages](https://ryoosxx.github.io/plo-pot-trainer/) で使えます。Safari / Chrome の「ホーム画面に追加」で、PC を閉じてもオフラインで開けます。

## セットアップ

Node.js 18 以上が必要です。

```bash
npm install
```

## コマンド

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発サーバーを起動 |
| `npm run build` | 本番ビルド |
| `npm run preview` | ビルド結果をプレビュー |
| `npm run test` | テストを 1 回実行 |
| `npm run test:watch` | テストを watch モードで実行 |
| `npm run typecheck` | TypeScript の型チェック |
| `npm run lint` | ESLint |
| `npm run format` | Prettier で整形 |
